QUESTIONS

The short version.

Is this a job board?↓

No. Signal is not a job board, an internship listing site or a placement service. It watches where opportunities appear in the fields you choose, like hackathons, calls for papers, research programmes, fellowships and internships, and tells you which fit where you are now. It promises no outcome and never ranks by name.

Do I need an AI key?↓

No. Heuristic search scores every item with your keyword rules and needs no key. Plug in a compatible model and each opportunity also gets a relevance from 0 to 10 and a brief: fit, stage, gains, asks, effort and first steps. Exclude terms and dedupe run before any model call.

Can I add my own sources?↓

Yes. In the demo console you can add an RSS or Atom feed, a JSON API with a field mapping, a page to watch, or a social feed through a feed URL. Each custom source keeps the name you give it. In the hosted app, the server will do the fetching.

Does Signal scrape X or LinkedIn?↓

No. For LinkedIn, Signal reads the notification mail that arrives in Gmail; reading mail is not available in the hosted app yet. For X or any other site, you can add a feed URL you are allowed to read. Signal does not scrape sites that forbid it.

Can I try it today?↓

Yes. The demo console runs on public sample rows. Any email and password signs you in, and nothing is sent anywhere.

How does match strength work?↓

Interest terms add 4 in titles or 3 in bodies. Boost terms add 2. Exclude terms archive rows.

Which notification channels exist?↓

Telegram. Discord is an inbound source, not a notification channel. There is no email sender.

Will the first run notify me about everything?↓

No. The first successful run stores the backfill without sending alerts.
